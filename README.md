One line, one laugh: a patient confesses to hearing voices, and the doctor's
first concern isn't the voices — it's whether they have health insurance.

## How it works

`main.ts` writes the single line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output`), checking first that it stays within the 200-character cap.
